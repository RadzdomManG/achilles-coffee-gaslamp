# ☕ Achilles Coffee Roasters (Gaslamp, San Diego) — Web Showcase

A curated, non-AI-looking, minimalist aesthetic web project for Achilles Coffee Roasters at 372 Fourth Ave, San Diego, CA.

## 🎨 Design System & Philosophy
- **Anti-"AI-Look" Rule:** Zero generic corporate blue/purple gradients, zero over-filtered stock photos, zero cluttered cards.
- **Palette:** Earthy tones inspired by specialty third-wave coffee shops:
  - Crema (`#FAF7F2`)
  - Warm Parchment (`#F3EDE2`)
  - Deep Espresso (`#1A1412`)
  - Terracotta Roast (`#A64B2A`)
  - Artisan Brass (`#C89D5C`)
- **Typography:** Editorial Serif (*Cormorant Garamond*) paired with crisp modern Sans (*Plus Jakarta Sans*) & Monospace accents (*JetBrains Mono*).

## 🚀 How to Run Locally
Buksan lang ang `index.html` gamit ang anumang browser (Chrome, Edge, Safari, Firefox), o gumamit ng Live Server sa VS Code / local server:

```bash
# Optional: if using python to serve locally
python -m http.server 3000
```
Then visit `http://localhost:3000`.
